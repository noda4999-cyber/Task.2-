لغة CSS ودورها في تنسيق صفحات الويب

إعداد الطالبه :ندي فتحي لمعي محمد ابراهيم عبدربة

الرقم الجامعي:2501096

إشراف الدكتوره : مها زغلول

المقدمة

تحتاج مواقع الويب إلي تنظيم المحتوي وتنسيقه حتي تظهر المعلومات بصورة واضحه وبها لمسات جمالية . وتستخدم لغة css للتحكم في ألوان الصفحات وخطوطها وترتيب عناصرها ،مما يجعل الموقع اسهل في القراءة والإستخدام .

أولاً : ما هي لغة CSS

CSS هي إختصار لـcascading style وتعني أوراق الأنماط المتتالية . وهي sheets لغة تستخدم لتحديد الشكل الخارجي لصفحات الويب ، مثل ألوان النصوص والخلفيات وأحجام الخطوط والمسافات بين العناصر وتعمل css مع html ، حيث تستخدم html لإنشاء محتوي الصفحة. مثل العناوين والفقرات ، بينما تحكم CSS في مظهر المحتوي ، مثلا يمكن إنشاء عنوان بإستخدام html ثم يتم تغيير لونه وحجمة بـ CSS ويساعد علي تعديل تصميم الموقع دون تغيير .

ثانياً : مكونات قاعدة CSS

قاعدة CSS تتكون من 3أجزاء أساسية :

  • المحدد(selector):العنصر اللي عايزين ننسقه .
  • الخاصية (property): الحاجة اللي عايزين نغيرها ، زي اللون وحجم الخط .
  • القيمة (value) : التغيير اللي عايزين نطبقة .

مثال

h1{color:blue;font-size:32px;}

يغير الكود إلي العنوان الأزرق و يحدد حجم خطة بـ 32 بكسل ، ويمكن إضافه CSS ب 3طرق داخل العنصر نفسة او داخل صفحة html أو في ملف خارجي مرتبط بالصفحه ، والطريقه الخارجية مناسبة لتنسيق عدة صفحات لأنها تساعد علي توحيد التصميم و تسهيل تعديلة .

ثالثاً : إستخدام CSS في تنسيق الصفحات

cssيساعد علي التحكم في الألوان والخطوط حيث أن :

الخاصية property الإستخدام
color لتحديد لون النص
back ground_color تحديد لون الخلفيه
font family نوع الخط
font_size حجم الخط
margin تحديد المسافة الخارجيه حول العنصر
padding تحديد المسافة الداخلية
border إضافة إطار

رابعاً : التصميم المتجاوب

يختلف حجم الشاشه بين الكمبيوتر والتليفون ، فتساعد CSS علي جعل الموقع مناسباً للأجهزة المختلفه فيعرف بالتصميم المتجاوب ، حيث تتغير أحجام العناصر وترتيبها حسب مساحة الشاشة ، كما تستخدم media queries لتطبيق تنسيقات معينة حسب عرض الشاشة ، فيجعل الموقع أسهل في التصفح

الخاتمة

الشكل التالي يوضح مثالاً لكود CSS وتنسيقة

تعد CSS جزءاً أساسياً من تصميم مواقع الويب ؛لأنها تساعد علي تنسيق المحتوي وتنظيمة والتحكم في الألوان والخطوط وتنظيم وتحكم في الألوان والخطوط والمسافات ، كما تجعل الصفحات مناسبة لمختلف الأجهزه ، مما يحسن تجربة المستخدم .
